##- Getting the Decent Sampler instruments to work

###1.Download Decent Sampler https://www.decentsamples.com/product/decent-sampler-plugin/

###2.Navigate to the Instruments folder inside the folder you downloaded from us.
           
###3.Locate the .dspreset file and open it using Decent Sampler.
            
###4.Your instrument should now be loaded and ready to use!
       
##How to Install and Use Serum 2 Presets
Purchase and install Serum 2 from 
 https://xferrecords.com/products/serum
            (Please note that Serum 2 is paid software and requires a valid license.)
           
2. Navigate to the Presets folder inside the folder you downloaded from us.

3. Locate the Serum 2 preset files and import them into Serum 2
            
4. Your presets should now be available to use in Serum 2!
